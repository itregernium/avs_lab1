# Вариант 4

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--kitchen (каталог)
|  |  +--old_menu (файл)
|  |  +--duck_recipe (файл)
|  +--chef_office (каталог)
|  |  +--barinov_notes (файл)
|  +--tasting_room (каталог)
|     +--tasting_scores (файл)
|     +--leva_comment (файл)
+--arcobaleno (каталог)
|  +--kitchen (каталог)
|  |  +--italian_menu (файл)
|  |  +--katya_recipe (файл)
|  +--office (каталог)
|  |  +--elena_plan (файл)
|  +--archive (каталог)
|     +--review_archive (файл)
+--critic_visit (файл)
```

Содержимое файлов:

```text
old_menu:

Лёва записывает замечания шефа
Последнее решение принимает Баринов

tasting_scores:
Блюдо Баринова получило девять баллов
Паста Кати получила восемь баллов
Десерт Луи получил десять баллов

leva_comment:

italian_menu:
Домашняя паста от Елены Павловны
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: rwxr-xr-x
claude_monet/kitchen: 750
old_menu: 644
duck_recipe: rw-r-----
chef_office: 710
barinov_notes: 600
tasting_room: rwxrwx---
tasting_scores: 640
leva_comment: r--r-----
arcobaleno: 755
arcobaleno/kitchen: владелец — все права; группа — чтение и исполнение; остальные — нет прав
italian_menu: 644
katya_recipe: rw-r-----
office: 750
elena_plan: r--r-----
archive: rwxr-x---
review_archive: 640
critic_visit: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `arcobaleno/kitchen/katya_recipe` в каталог `claude_monet/kitchen` под именем `new_recipe`.
2. Рекурсивно скопировать каталог `arcobaleno/archive` в каталог `claude_monet/chef_office` под именем `reviews_copy`.
3. В каталоге `arcobaleno/office` создать относительную символическую ссылку `chef_recipe`, указывающую на файл `arcobaleno/kitchen/katya_recipe`.
4. В корне `lab0` создать символическую ссылку `rival_kitchen` на каталог `arcobaleno/kitchen`.
5. Создать жёсткую ссылку `claude_monet/tasting_room/critic_copy` на файл `lab0/critic_visit`.
6. Объединить содержимое файлов `claude_monet/kitchen/old_menu` и `arcobaleno/kitchen/italian_menu` в новый файл `claude_monet/tasting_room/menu_comparison`.
7. Дописать содержимое файла `claude_monet/tasting_room/leva_comment` в конец файла `critic_visit`.
8. Переместить файл `claude_monet/chef_office/barinov_notes` в каталог `claude_monet/tasting_room` под именем `chef_verdict`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, исключить имена с сочетанием `copy`, отсортировать строки по размеру файла как по числу в порядке убывания и вывести первые пять строк.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet` и `arcobaleno`. Вывести без имён файлов строки, содержащие сочетание `баринов` или `катя` в любом регистре, исключить строки с сочетанием `десерт`, отсортировать результат по алфавиту и оставить первые шесть строк.
3. Определить, сколько файлов в каталогах `claude_monet/kitchen` и `arcobaleno/kitchen` содержат сочетание букв `блюд` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из файлов, имена которых заканчиваются на `_menu` и которые находятся в кухнях обоих ресторанов, получить последние две строки без служебных заголовков. Оставить строки с сочетанием `десерт` или `суп` в любом регистре и отсортировать их в обратном алфавитном порядке.
5. Из файла `claude_monet/tasting_room/menu_comparison` исключить строки с сочетанием `десерт`, отсортировать остальные строки в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Отсортировать полученные строки по номеру inode как по числу.
7. В файлах каталога `claude_monet/chef_office/reviews_copy` выбрать без вывода имён файлов строки, содержащие сочетание `гост` или `меню` в любом регистре, исключить строки с именем `Елена`, отсортировать результат и подсчитать количество оставшихся строк.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить исходный файл `arcobaleno/kitchen/katya_recipe`.
2. Удалить символическую ссылку `arcobaleno/office/chef_recipe`.
3. Удалить символическую ссылку `rival_kitchen`.
4. Удалить исходный файл `critic_visit`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `claude_monet/tasting_room/critic_copy`.
6. Удалить файл `arcobaleno/archive/review_archive`.
7. Удалить ставший пустым каталог `arcobaleno/archive` при помощи `rmdir`.
8. Удалить каталог `claude_monet/chef_office/reviews_copy` со всем его содержимым.
