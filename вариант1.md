# Вариант 1

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--kitchen (каталог)
|  |  +--hot_station (каталог)
|  |  |  +--barinov_order (файл)
|  |  |  +--senya_task (файл)
|  |  +--cold_station (каталог)
|  |  |  +--fedya_task (файл)
|  |  +--menu_draft (файл)
|  +--hall (каталог)
|  |  +--reservations (файл)
|  |  +--guest_reviews (файл)
|  +--office (каталог)
|     +--vika_schedule (файл)
+--locker_room (каталог)
|  +--max_resume (файл)
|  +--leva_note (файл)
+--nagiev_message (файл)
+--first_shift (файл)
```

Содержимое файлов:

```text
barinov_order:
Подготовить горячий цех к вечерней смене
Проверить рабочие места поваров
Макса к плите без разрешения не подпускать

senya_task:
Сеня отвечает за мясные блюда
Получить продукты на складе
Перед закрытием проверить остатки

fedya_task:
Федя отвечает за рыбные блюда
Проверить свежесть сибаса и дорадо
Подготовить холодные закуски для гостей

menu_draft:
Утиная ножка с овощами
Луковый суп по рецепту шефа
Фирменный десерт от Луи
Новое блюдо Макса отправлено на доработку

reservations:
Столик 3 забронирован на восемнадцать часов
Столик 7 подготовить для постоянных гостей
Большой стол оставить для вечернего банкета

guest_reviews:
Гости похвалили десерт и работу официантов
Один гость слишком долго ждал горячее блюдо
Постоянные гости попросили вернуть старое меню
Новый повар Макс показался гостям растерянным

vika_schedule:
Вика проводит собрание перед открытием ресторана
В семнадцать часов проверить готовность зала
После смены принять отчёт от Макса

max_resume:
Максим Лавров приехал в Москву из Воронежа
Хочет стать профессиональным поваром
Готов работать в ресторане Claude Monet
Опыта мало, но желания много

leva_note:
Лёва должен показать Максу рабочее место
Объяснить правила кухни и порядок выдачи блюд
О результате доложить Виктору Петровичу

nagiev_message:
Владелец ресторана приедет вечером
Подготовить лучший стол в зале
Баринов должен лично представить новое меню

first_shift:
Макс прибыл в ресторан вовремя
Лёва выдал ему форму
Первая задача получена от шефа
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
kitchen: rwxr-x---
hot_station: 770
barinov_order: rw-r-----
senya_task: 640
cold_station: владелец — все права; группа — чтение и исполнение; остальные — нет прав
fedya_task: 600
menu_draft: rw-r--r--
hall: 755
reservations: rw-rw-r--
guest_reviews: 444
office: rwx--x---
vika_schedule: 640
locker_room: rwxr-x---
max_resume: 600
leva_note: r--r-----
nagiev_message: 444
first_shift: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `locker_room/max_resume` в каталог `claude_monet/office` под именем `candidate_max`.
2. Рекурсивно скопировать каталог `claude_monet/hall` в каталог `claude_monet/kitchen` под именем `hall_backup`.
3. В каталоге `locker_room` создать относительную символическую ссылку `first_menu`, указывающую на файл `claude_monet/kitchen/menu_draft`.
4. В корне `lab0` создать символическую ссылку `guest_zone` на каталог `claude_monet/hall`.
5. Создать жёсткую ссылку `claude_monet/kitchen/shift_plan` на файл `lab0/first_shift`.
6. Объединить содержимое файлов `claude_monet/kitchen/hot_station/senya_task` и `claude_monet/kitchen/cold_station/fedya_task` в новый файл `claude_monet/kitchen/team_tasks`.
7. Дописать содержимое файла `locker_room/leva_note` в конец файла `first_shift`.
8. Переместить файл `nagiev_message` в каталог `claude_monet/office` под именем `owner_message`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить в нём только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке убывания и вывести первые пять строк результата.
2. Рекурсивно просмотреть содержимое файлов в `lab0`. Вывести без имён файлов строки, содержащие сочетание букв `макс` в любом регистре, исключить строки со словом `отчёт`, отсортировать результат в обратном алфавитном порядке и оставить первые четыре строки.
3. В исходных файлах, имена которых заканчиваются на `_task` и которые находятся в каталогах `hot_station` и `cold_station`, выбрать строки с сочетаниями букв `блюд` или `продукт` в любом регистре. Отсортировать выбранные строки по алфавиту и подсчитать общее количество слов в них.
4. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по имени файла в обратном алфавитном порядке.
5. Для каждого файла каталога `claude_monet/kitchen/hot_station` получить первую и последнюю строку. Объединить результат без служебных заголовков, возникающих при обработке нескольких файлов, и отсортировать строки по алфавиту.
6. Из файла `claude_monet/hall/guest_reviews` выбрать строки с сочетанием букв `гост` в любом регистре, исключить строки с сочетанием `постоянн`, отсортировать результат в обратном алфавитном порядке и вывести первые две строки.
7. Рекурсивно определить, сколько файлов внутри `claude_monet/kitchen/hall_backup` содержат сочетание букв `гост` хотя бы один раз. Подсчитать количество файлов, а не количество найденных строк.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить исходный файл `locker_room/max_resume`.
2. Удалить символическую ссылку `locker_room/first_menu`.
3. Удалить символическую ссылку `guest_zone`.
4. Удалить исходный файл `first_shift`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `claude_monet/kitchen/shift_plan`.
6. Удалить файл `claude_monet/kitchen/cold_station/fedya_task`.
7. Удалить ставший пустым каталог `claude_monet/kitchen/cold_station` при помощи `rmdir`.
8. Удалить каталог `claude_monet/kitchen/hall_backup` со всем его содержимым.
