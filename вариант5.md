# Вариант 5

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--eleon (каталог)
|  +--victor (каталог)
|  |  +--kitchen (каталог)
|  |  |  +--new_menu (файл)
|  |  |  +--dinner_order (файл)
|  |  +--hall (каталог)
|  |     +--opening_guests (файл)
|  +--hotel_office (каталог)
|  |  +--eleonora_order (файл)
|  +--reception (каталог)
|  |  +--sofia_schedule (файл)
|  |  +--guest_notes (файл)
|  +--staff_room (каталог)
|  |  +--barinov_uniform (файл)
|  |  +--kostya_message (файл)
|  +--roof (каталог)
|     +--max_letter (файл)
|     +--roof_event (файл)
+--opening_day (файл)
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
eleon: 755
victor: rwxr-x---
kitchen: 750
new_menu: rw-r--r--
dinner_order: 640
hall: rwxrwx---
opening_guests: 644
hotel_office: 710
eleonora_order: r--r-----
reception: владелец — все права; группа — чтение и исполнение; остальные — только исполнение
sofia_schedule: 640
guest_notes: rw-r-----
staff_room: 750
barinov_uniform: 600
kostya_message: r--r-----
roof: rwxr-x---
max_letter: 640
roof_event: r--r-----
opening_day: 644
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `eleon/hotel_office/eleonora_order` в каталог `eleon/victor/hall` под именем `owner_order`.
2. Рекурсивно скопировать каталог `eleon/roof` в каталог `eleon/victor` под именем `roof_archive`.
3. В каталоге `eleon/staff_room` создать относительную символическую ссылку `current_menu`, указывающую на файл `eleon/victor/kitchen/new_menu`.
4. В корне `lab0` создать символическую ссылку `hotel_reception` на каталог `eleon/reception`.
5. Создать жёсткую ссылку `eleon/victor/hall/opening_log` на файл `lab0/opening_day`.
6. Объединить содержимое файлов `eleon/victor/hall/opening_guests` и `eleon/reception/guest_notes` в новый файл `eleon/reception/all_guests`.
7. Дописать содержимое файла `eleon/staff_room/kostya_message` в конец файла `opening_day`.
8. Переместить файл `eleon/roof/max_letter` в каталог `eleon/hotel_office` под именем `max_message`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `eleon`. Оставить только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке убывания и вывести первые шесть строк результата.
2. Рекурсивно просмотреть содержимое файлов в `eleon`. Вывести без имён файлов строки, содержащие сочетание `баринов` или `софия` в любом регистре, исключить строки с сочетанием `гост`, отсортировать результат по алфавиту и оставить первые пять строк.
3. Определить, сколько файлов в каталогах `eleon/victor/hall` и `eleon/reception` содержат сочетание букв `гост` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Для каждого файла каталога `eleon/reception` получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `гост` или `соф` в любом регистре и отсортировать их в обратном алфавитном порядке.
5. Из файла `eleon/reception/all_guests` исключить строки с сочетанием `столик`, отсортировать остальные строки в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по имени файла.
7. Рекурсивно определить, сколько файлов внутри `eleon/victor/roof_archive` содержат сочетание `баринов` или `макс` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить исходный файл `eleon/hotel_office/eleonora_order`.
2. Удалить символическую ссылку `eleon/staff_room/current_menu`.
3. Удалить символическую ссылку `hotel_reception`.
4. Удалить исходный файл `opening_day`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `eleon/victor/hall/opening_log`.
6. Удалить файл `eleon/roof/roof_event`.
7. Удалить ставший пустым каталог `eleon/roof` при помощи `rmdir`.
8. Удалить каталог `eleon/victor/roof_archive` со всем его содержимым.
