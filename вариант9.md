# Вариант 9

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--bar (каталог)
|  |  +--cocktail_menu (файл)
|  |  +--evening_orders (файл)
|  +--wine_cellar (каталог)
|  |  +--inventory (файл)
|  |  +--nagiev_wine (файл)
|  +--storage (каталог)
|  |  +--supplier_note (файл)
|  +--hall (каталог)
|  |  +--reservations (файл)
|  |  +--nastya_note (файл)
|  +--office (каталог)
|     +--vika_schedule (файл)
+--kostya_room (каталог)
|  +--kostya_diary (файл)
+--empty_crates (каталог)
+--bar_message (файл)
```

Содержимое файлов:

```text
cocktail_menu:
Фирменный коктейль от Кости
Лимонад для Насти без сахара
Классический напиток для постоянных гостей
Новый коктейль показать Вике вечером

evening_orders:
Столик два заказал три коктейля
Для банкета подготовить холодные напитки
Нагиев ждёт свой заказ у барной стойки
Последний заказ принимает Костя

inventory:
В погребе осталось двенадцать бутылок вина
Красное вино заказано для банкета
Белое вино подадут к рыбе Феди
Костя проверит остатки после закрытия

nagiev_wine:
Нагиев попросил оставить любимое вино
Бутылку перенесли на отдельную полку
Костя отвечает за специальный заказ
Подать вино после приезда владельца

supplier_note:
Поставщик привезёт напитки утром
Новая партия вина отмечена в накладной
Костя должен проверить количество коробок
О повреждениях сразу сообщить Вике

reservations:
Столик четыре забронирован на вечер
У окна ждут постоянных гостей
Большой стол подготовить для банкета
Вика утвердит план рассадки

nastya_note:
Настя передаёт заказы Косте лично
Гостям за пятым столиком нужна вода
На банкете напитки подают после закусок
Последний заказ проверить перед закрытием

vika_schedule:
Вика проверяет бар до открытия
Днём проходит встреча с поставщиком
Перед банкетом нужно сверить заказы
После смены Костя сдаёт отчёт

kostya_diary:
Костя открыл бар раньше обычного
Настя помогла расставить бокалы
Нагиев похвалил новый коктейль
Вечером друзья встретились после смены

bar_message:
Бар открывается вместе с рестораном
Костя назначен ответственным за напитки
Вика ждёт отчёт об остатках
Нагиев приедет после восьми часов
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
bar: rwxr-x---
cocktail_menu: 644
evening_orders: rw-r-----
wine_cellar: 750
inventory: rw-rw----
nagiev_wine: 640
storage: владелец — все права; группа — чтение и исполнение; остальные — нет прав
supplier_note: rw-r--r--
hall: 755
reservations: 664
nastya_note: r--r--r--
office: rwxr-x---
vika_schedule: 640
kostya_room: 750
kostya_diary: r--r-----
empty_crates: 700
bar_message: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `kostya_room/kostya_diary` в каталог `claude_monet/office` под именем `bartender_report`.
2. Рекурсивно скопировать каталог `claude_monet/wine_cellar` в каталог `claude_monet/storage` под именем `cellar_backup`.
3. В каталоге `kostya_room` создать относительную символическую ссылку `today_orders`, указывающую на файл `claude_monet/bar/evening_orders`.
4. В корне `lab0` создать символическую ссылку `bar_entrance` на каталог `claude_monet/bar`.
5. Создать жёсткую ссылку `claude_monet/bar/owner_message` на файл `bar_message`.
6. Объединить содержимое файлов `claude_monet/hall/reservations` и `claude_monet/hall/nastya_note` в новый файл `claude_monet/hall/service_plan`.
7. Дописать содержимое файла `claude_monet/storage/supplier_note` в конец файла `claude_monet/wine_cellar/inventory`.
8. Переместить файл `claude_monet/wine_cellar/nagiev_wine` в каталог `claude_monet/office` под именем `special_wine`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, исключить имена с сочетанием `report`, отсортировать строки по размеру файла как по числу в порядке убывания и вывести первые пять строк.
2. Рекурсивно просмотреть содержимое файлов в `lab0`. Вывести без имён файлов строки, содержащие сочетание `костя` или `настя` в любом регистре, исключить строки с сочетанием `отчёт`, отсортировать результат в обратном алфавитном порядке и оставить первые шесть строк.
3. Определить, сколько файлов в исходном каталоге `claude_monet/wine_cellar` и его копии `claude_monet/storage/cellar_backup` содержат сочетание букв `вино` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из файлов `claude_monet/bar/cocktail_menu` и `claude_monet/bar/evening_orders` получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `коктейл` или `заказ` в любом регистре и отсортировать их по алфавиту.
5. Из файла `claude_monet/hall/service_plan` исключить строки с сочетанием `послед`, выбрать строки с сочетанием `гост` или `заказ`, отсортировать их в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по номеру inode как по числу.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, отсортировать их по имени ссылки в обратном алфавитном порядке и вывести первую строку результата.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить исходный файл `kostya_room/kostya_diary`.
2. Удалить символическую ссылку `kostya_room/today_orders`.
3. Удалить символическую ссылку `bar_entrance`.
4. Удалить исходный файл `bar_message`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `claude_monet/bar/owner_message`.
6. Удалить файл `claude_monet/storage/supplier_note`.
7. Удалить пустой каталог `empty_crates` при помощи `rmdir`.
8. Удалить каталог `claude_monet/storage/cellar_backup` со всем его содержимым.
