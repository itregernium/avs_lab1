# Вариант 3

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--hall (каталог)
|  |  +--table_plan (файл)
|  |  +--guest_requests (файл)
|  +--reception (каталог)
|  |  +--reservations (файл)
|  |  +--complaints (файл)
|  +--bar (каталог)
|  |  +--kostya_shift (файл)
|  |  +--cocktail_card (файл)
|  +--terrace (каталог)
|  |  +--banquet_plan (файл)
|  +--kitchen (каталог)
|  |  +--special_orders (файл)
|  +--staff_room (каталог)
|     +--nastya_note (файл)
+--vika_report (файл)
+--nagiev_call (файл)
```

Содержимое файлов:

```text
table_plan:
Столик 1 закреплён за Настей
Столик 4 обслуживает Саша
Столик 7 оставить для Дмитрия Нагиева
Большой стол подготовить к банкету

guest_requests:
Гости у окна просят позвать Вику
За столиком 4 ждут десерт от Луи
Постоянный гость заказал блюдо Баринова

reservations:
Семья заказала столик на шесть часов
Друзья Кости придут после вечерней смены
Для владельца ресторана оставлен столик 7
Настя подтвердила все бронирования

complaints:
Гость слишком долго ждал горячее
За столиком 2 перепутали заказ
Вика обещала лично решить проблему

kostya_shift:
Костя открывает бар перед обедом
Проверяет запасы и получает лёд
После закрытия сдаёт отчёт Вике

cocktail_card:
Коктейль от Кости с вишнёвым соком
Безалкогольный напиток для Насти

banquet_plan:
На террасе поставить восемь столов

special_orders:
Столик 1 просит блюдо без лука

nastya_note:
Настя поменялась сменой с официанткой
Костя обещал встретить её после работы
Вика разрешила закончить смену раньше

vika_report:
Зал готов к открытию
Официанты получили свои столики
Все жалобы нужно передать Вике

Дмитрий Нагиев позвонил перед открытием
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
hall: rwxr-xr-x
table_plan: 644
guest_requests: rw-r-----
reception: 750
reservations: rw-r--r--
complaints: 600
bar: владелец — все права; группа — чтение и исполнение; остальные — только исполнение
kostya_shift: 640
cocktail_card: r--r--r--
terrace: 750
banquet_plan: rw-r-----
kitchen: rwxr-x---
special_orders: 640
staff_room: 750
nastya_note: r--r-----
vika_report: 644
nagiev_call: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `vika_report` в каталог `claude_monet/reception` под именем `manager_report`.
2. Рекурсивно скопировать каталог `claude_monet/terrace` в каталог `claude_monet/hall` под именем `terrace_backup`.
3. В каталоге `claude_monet/bar` создать относительную символическую ссылку `current_reservations`, указывающую на файл `claude_monet/reception/reservations`.
4. В корне `lab0` создать символическую ссылку `guest_hall` на каталог `claude_monet/hall`.
5. Создать жёсткую ссылку `claude_monet/reception/owner_call` на файл `lab0/nagiev_call`.
6. Объединить содержимое файлов `claude_monet/reception/reservations` и `claude_monet/terrace/banquet_plan` в новый файл `claude_monet/reception/evening_guests`.
7. Дописать содержимое файла `claude_monet/staff_room/nastya_note` в конец файла `vika_report`.
8. Переместить файл `claude_monet/reception/complaints` в каталог `claude_monet/hall` под именем `guest_complaints`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `claude_monet`. Оставить только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке убывания и вывести первые шесть строк результата.
2. Рекурсивно просмотреть содержимое файлов в `lab0`. Вывести без имён файлов строки, содержащие сочетание `вик` или `наст` в любом регистре, исключить строки с сочетанием `столик`, отсортировать результат в обратном алфавитном порядке и оставить первые пять строк.
3. Определить, сколько файлов среди `claude_monet/hall/table_plan`, `claude_monet/hall/guest_requests`, `claude_monet/hall/guest_complaints` и файлов каталога `claude_monet/hall/terrace_backup` содержат сочетание букв `гост` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из файлов `claude_monet/bar/kostya_shift` и `claude_monet/bar/cocktail_card` получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `кост` или `вик` в любом регистре и отсортировать их по алфавиту.
5. Из файла `claude_monet/reception/evening_guests` исключить строки с сочетанием `столик`, отсортировать оставшиеся строки в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по имени файла в обратном алфавитном порядке.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, исключить ссылки с сочетанием `guest` в имени и отсортировать оставшиеся строки по имени ссылки.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить файл `claude_monet/staff_room/nastya_note`.
2. Удалить символическую ссылку `claude_monet/bar/current_reservations`.
3. Удалить символическую ссылку `guest_hall`.
4. Удалить исходный файл `nagiev_call`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `claude_monet/reception/owner_call`.
6. Удалить файл `claude_monet/terrace/banquet_plan`.
7. Удалить ставший пустым каталог `claude_monet/terrace` при помощи `rmdir`.
8. Удалить каталог `claude_monet/hall/terrace_backup` со всем его содержимым.
