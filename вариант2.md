# Вариант 2

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--kitchen (каталог)
|  |  +--hot_station (каталог)
|  |  |  +--senya_inventory (файл)
|  |  |  +--meat_order (файл)
|  |  +--cold_station (каталог)
|  |  |  +--fedya_inventory (файл)
|  |  |  +--fish_order (файл)
|  +--freezer (каталог)
|  |  +--reserve_list (файл)
|  +--pantry (каталог)
|  |  +--missing_products (файл)
|  +--chef_office (каталог)
|  |  +--barinov_report (файл)
|  +--staff_room (каталог)
|     +--prank_plan (файл)
|     +--leva_warning (файл)

```


## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: rwxr-xr-x
kitchen: 750
hot_station: rwxrwx---
senya_inventory: 640
meat_order: rw-r--r--
cold_station: 750
fedya_inventory: rw-r-----
fish_order: 644
freezer: владелец — все права; группа — чтение и исполнение; остальные — нет прав
reserve_list: 600
pantry: 750
missing_products: rw-r-----
chef_office: 710
barinov_report: r--r-----
staff_room: rwxr-x---
prank_plan: 600
leva_warning: r--r-----
evening_incident: 644
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `claude_monet/chef_office/barinov_report` в каталог `claude_monet/staff_room` под именем `shift_order`.
2. Рекурсивно скопировать каталог `claude_monet/kitchen/cold_station` в каталог `claude_monet/staff_room` под именем `cold_backup`.
3. В каталоге `claude_monet/chef_office` создать относительную символическую ссылку `product_loss`, указывающую на файл `claude_monet/pantry/missing_products`.
4. В корне `lab0` создать символическую ссылку `kitchen_work` на каталог `claude_monet/kitchen`.
5. Создать жёсткую ссылку `claude_monet/kitchen/incident_copy` на файл `lab0/evening_incident`.
6. Объединить содержимое файлов `claude_monet/kitchen/hot_station/senya_inventory` и `claude_monet/kitchen/cold_station/fedya_inventory` в новый файл `claude_monet/kitchen/total_inventory`.
7. Дописать содержимое файла `claude_monet/staff_room/leva_warning` в конец файла `evening_incident`.
8. Переместить файл `claude_monet/staff_room/prank_plan` в каталог `claude_monet/chef_office` под именем `senya_explanation`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, исключить имена, заканчивающиеся на `_copy`, отсортировать строки по размеру файла как по числу в порядке возрастания и вывести последние четыре строки результата.
2. Рекурсивно просмотреть содержимое файлов в `lab0`. Вывести без имён файлов строки, содержащие сочетание `сеня` или `федя` в любом регистре, исключить строки со словом `Баринов`, отсортировать оставшиеся строки по алфавиту и вывести первые шесть строк.
3. Определить, сколько файлов в исходном каталоге `claude_monet/kitchen/cold_station` и его копии `claude_monet/staff_room/cold_backup` содержат сочетание букв `рыб` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из каждого исходного файла с окончанием имени `_inventory` в каталогах `hot_station` и `cold_station` получить последние две строки без служебных заголовков. Оставить строки с сочетаниями `проверил` или `оста` в любом регистре и отсортировать их в обратном алфавитном порядке.
5. Из файла `claude_monet/kitchen/total_inventory` исключить строки, содержащие имена `Сеня` или `Федя`, отсортировать оставшиеся строки в обратном алфавитном порядке, взять первые три и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только символические ссылки и отсортировать полученные строки по имени ссылки в обратном алфавитном порядке.
7. В файлах `claude_monet/chef_office/barinov_report`, `claude_monet/staff_room/shift_order` и `claude_monet/staff_room/leva_warning` выбрать без вывода имён файлов строки, содержащие сочетание `кух` или `шеф` в любом регистре. Исключить строки с сочетанием `после`, отсортировать результат в обратном алфавитном порядке и подсчитать общее количество слов.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить исходный файл `claude_monet/chef_office/barinov_report`.
2. Удалить символическую ссылку `claude_monet/chef_office/product_loss`.
3. Удалить символическую ссылку `kitchen_work`.
4. Удалить исходный файл `evening_incident`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `claude_monet/kitchen/incident_copy`.
6. Удалить файл `claude_monet/freezer/reserve_list`.
7. Удалить ставший пустым каталог `claude_monet/freezer` при помощи `rmdir`.
8. Удалить каталог `claude_monet/staff_room/cold_backup` со всем его содержимым.
