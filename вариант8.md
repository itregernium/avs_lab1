# Вариант 8

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--kitchen (каталог)
|  |  +--morning_shift (каталог)
|  |  |  +--senya_tasks (файл)
|  |  |  +--fedya_tasks (файл)
|  |  +--evening_shift (каталог)
|  |  |  +--max_tasks (файл)
|  |  |  +--denis_tasks (файл)
|  |  +--leva_order (файл)
|  +--hall (каталог)
|  |  +--table_plan (файл)
|  |  +--complaints (файл)
|  +--office (каталог)
|     +--barinov_schedule (файл)
+--staff_room (каталог)
|  +--late_report (файл)
+--reserve_empty (каталог)
+--shift_message (файл)
```

Содержимое файлов:

```text
senya_tasks:
Сеня принимает мясо в начале смены
До открытия нужно подготовить горячий цех
Лёва ждёт отчёт о продуктах
После обеда проверить остатки на складе

fedya_tasks:
Федя проверяет свежесть рыбы
Утром подготовить холодные закуски
Перед подачей показать блюдо Лёве
В конце смены убрать рабочее место

max_tasks:
Макс приходит на вечернюю смену
Первое блюдо готовится для седьмого столика
Баринов поручил Максу новый соус
После закрытия помочь Лёве с отчётом

denis_tasks:
Денис выступает перед гостями вечером
До концерта он помогает на кухне
В середине смены приготовить заказ Нагиева
Последнее блюдо передать официантам

leva_order:
Лёва распределяет задачи между поварами
Утренняя смена готовит ресторан к открытию
Вечерняя смена отвечает за банкет
Все отчёты передать Лёве после закрытия

table_plan:
Столик один обслуживает Настя
Столик три оставить для постоянных гостей
Столик семь принимает большой заказ
Банкетный стол подготовить к вечеру

complaints:
Гость долго ждал блюдо от Макса
За третьим столиком забыли принести напитки
Один заказ вернули на кухню
Вика просит разобрать жалобы после смены

barinov_schedule:
Баринов приходит на кухню до открытия
В полдень шеф проверяет утреннюю смену
Перед банкетом проходит общее собрание
Лёва докладывает шефу после закрытия

late_report:
Сеня опоздал на утреннюю смену
Макс перепутал время собрания
Лёва записал объяснения поваров
Повторные опоздания передадут Баринову

shift_message:
Команда собирается за час до открытия
Лёва назначен старшим на текущую смену
Вика проверяет готовность зала
Баринов ждёт общий отчёт утром
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
kitchen: rwxr-x---
morning_shift: 750
senya_tasks: rw-r-----
fedya_tasks: 640
evening_shift: владелец — все права; группа — чтение и исполнение; остальные — нет прав
max_tasks: 644
denis_tasks: rw-r--r--
leva_order: 660
hall: rwxr-xr-x
table_plan: 644
complaints: rw-rw-r--
office: 750
barinov_schedule: rw-r-----
staff_room: rwxr-x---
late_report: 640
reserve_empty: 700
shift_message: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `staff_room/late_report` в каталог `claude_monet/office` под именем `discipline_report`.
2. Рекурсивно скопировать каталог `claude_monet/kitchen/morning_shift` в каталог `claude_monet/kitchen/evening_shift` под именем `morning_backup`.
3. В каталоге `staff_room` создать относительную символическую ссылку `current_order`, указывающую на файл `claude_monet/kitchen/leva_order`.
4. В корне `lab0` создать символическую ссылку `shift_kitchen` на каталог `claude_monet/kitchen`.
5. Создать жёсткую ссылку `claude_monet/kitchen/common_message` на файл `shift_message`.
6. Объединить содержимое файлов `claude_monet/kitchen/morning_shift/senya_tasks` и `claude_monet/kitchen/morning_shift/fedya_tasks` в новый файл `claude_monet/kitchen/morning_report`.
7. Дописать содержимое файла `claude_monet/office/barinov_schedule` в конец файла `claude_monet/kitchen/leva_order`.
8. Переместить файл `claude_monet/hall/complaints` в каталог `claude_monet/office` под именем `guest_complaints`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке убывания и вывести первые пять строк результата.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet`. Вывести без имён файлов строки, содержащие сочетание `смен` или `лёва` в любом регистре, исключить строки с сочетанием `отчёт`, отсортировать результат по алфавиту и оставить первые шесть строк.
3. Определить, сколько файлов в исходном каталоге `claude_monet/kitchen/morning_shift` и его копии `claude_monet/kitchen/evening_shift/morning_backup` содержат сочетание букв `смен` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из файлов, имена которых заканчиваются на `_tasks` и которые находятся в каталогах `morning_shift` и `evening_shift`, получить последние две строки без служебных заголовков. Оставить строки с сочетанием `лёва` или `смен` в любом регистре и отсортировать их в обратном алфавитном порядке.
5. Из файла `claude_monet/kitchen/morning_report` исключить строки с именами `Сеня` и `Федя`, отсортировать оставшиеся строки в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Отсортировать полученные строки по имени файла.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, исключить ссылки с сочетанием `shift` в имени и отсортировать оставшиеся строки по имени ссылки в обратном алфавитном порядке.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить исходный файл `staff_room/late_report`.
2. Удалить символическую ссылку `staff_room/current_order`.
3. Удалить символическую ссылку `shift_kitchen`.
4. Удалить исходный файл `shift_message`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `claude_monet/kitchen/common_message`.
6. Удалить файл `claude_monet/kitchen/evening_shift/denis_tasks`.
7. Удалить пустой каталог `reserve_empty` при помощи `rmdir`.
8. Удалить каталог `claude_monet/kitchen/evening_shift/morning_backup` со всем его содержимым.
