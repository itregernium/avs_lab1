# Вариант 15

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--kitchen (каталог)
|  |  +--hot_station (каталог)
|  |  |  +--senya_task (файл)
|  |  |  +--fedya_task (файл)
|  |  +--pastry_station (каталог)
|  |  |  +--lui_dessert (файл)
|  |  |  +--katya_idea (файл)
|  |  +--barinov_order (файл)
|  +--hall (каталог)
|  |  +--waiter_plan (файл)
|  +--bar (каталог)
|  |  +--kostya_report (файл)
|  |  +--nastya_note (файл)
|  +--office (каталог)
|  |  +--vika_summary (файл)
|  +--locker_room (каталог)
|     +--max_note (файл)
|     +--leva_note (файл)
```

Содержимое файлов:

```text
senya_task:

Проверяет температуру горячего цеха
После смены считает оставшиеся продукты

fedya_task:
Федя разделывает рыбу для гостей
Готовит фирменную закуску вместе с Сеней
Перед подачей зовёт Баринова

lui_dessert:
Луи выпекает коржи для мильфея
Готовит крем по старому рецепту
Оставляет один десерт для команды

katya_idea:
Катя предлагает новый шоколадный десерт
Баринов просит уменьшить количество сахара
Пробную порцию получает Макс

barinov_order:
Баринов собирает всю команду перед сменой
Каждый повар отвечает за своё рабочее место
Лёва контролирует выдачу блюд

waiter_plan:
Настя обслуживает столики у окна
Официанты встречают гостей в главном зале

kostya_report:
Костя проверил запас напитков
Для вечера подготовлены новые коктейли

nastya_note:
Настя просит Костю не опаздывать
После смены они ужинают вместе
Для гостей оставлены чистые бокалы

vika_summary:
Вика проверила кухню и главный зал
Команда готова к вечерней смене
Отчёт нужно передать Нагиеву

max_note:
Макс придумал новое блюдо для меню
Баринов разрешил приготовить пробную порцию
Вика ждёт Макса после смены

leva_note:
Лёва проверяет форму новых поваров
Ключ от кладовой лежит у шефа
Последним кухню закрывает су-шеф
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
kitchen: rwxr-x---
hot_station: 750
senya_task: rw-r-----
fedya_task: 640
pastry_station: владелец — все права; группа — чтение и исполнение; остальные — нет прав
lui_dessert: 644
katya_idea: rw-r--r--
barinov_order: 640
hall: rwxr-x---
waiter_plan: 644
bar: 750
kostya_report: владелец — чтение и запись; группа — чтение; остальные — нет прав
nastya_note: 640
office: rwxr-x---
vika_summary: 640
locker_room: 750
max_note: rw-r-----
leva_note: 644
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `claude_monet/locker_room/max_note` в каталог `claude_monet/office` под именем `max_report`.
2. Рекурсивно скопировать каталог `claude_monet/bar` в каталог `claude_monet/hall` под именем `bar_backup`.
3. В корне `lab0` создать символическую ссылку `final_menu`, указывающую на файл `claude_monet/kitchen/barinov_order`.
4. В каталоге `claude_monet/office` создать относительную символическую ссылку `kitchen_access`, указывающую на каталог `../kitchen`.
5. Создать жёсткую ссылку `claude_monet/kitchen/hot_station/senya_task_copy` на файл `claude_monet/kitchen/hot_station/senya_task`.
6. Объединить содержимое файлов `claude_monet/kitchen/hot_station/senya_task` и `claude_monet/kitchen/hot_station/fedya_task` в новый файл `claude_monet/kitchen/cook_tasks`.
7. Дописать содержимое файла `claude_monet/hall/waiter_plan` в конец файла `claude_monet/office/vika_summary`.
8. Переместить файл `claude_monet/locker_room/max_note` в каталог `claude_monet/kitchen` под именем `max_final_note`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений ввода-вывода и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке убывания и вывести первые пять строк результата.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet`. Вывести без имён файлов строки, содержащие сочетание `баринов` или `макс` в любом регистре, исключить строки с сочетанием `порц`, отсортировать результат по алфавиту и оставить первые шесть строк.
3. Определить, сколько файлов в исходном каталоге `claude_monet/bar` и его копии `claude_monet/hall/bar_backup` содержат сочетание `кост` или `наст` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из исходных файлов каталога `claude_monet/kitchen/hot_station`, имена которых заканчиваются на `_task`, получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `сеня`, `федя` или `продукт` в любом регистре и отсортировать их в обратном алфавитном порядке.
5. Из файла `claude_monet/kitchen/cook_tasks` исключить строки с именами `Сеня` и `Федя`, отсортировать оставшиеся строки в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по номеру inode как по числу.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, исключить ссылки с сочетанием `final` в имени и отсортировать оставшиеся строки по имени ссылки.
