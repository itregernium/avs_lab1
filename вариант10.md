## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--hall (каталог)
|  |  +--tables (каталог)
|  |  |  +--table_three (файл)
|  |  |  +--table_seven (файл)
|  |  +--waiters (каталог)
|  |  |  +--shift_list (файл)
|  |  |  +--tip_report (файл)
|  |  +--guest_requests (файл)
|  +--kitchen (каталог)
|  |  +--vegetarian_menu (файл)
|  |  +--barinov_order (файл)
|  +--office (каталог)
|     +--vika_instruction (файл)
+--nastya_room (каталог)
|  +--nastya_diary (файл)
+--free_tables (каталог)
+--evening_message (файл)
```

Содержимое файлов:


## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
hall: rwxr-x---
tables: 750
table_three: rw-r-----
table_seven: 640
waiters: владелец — все права; группа — чтение и исполнение; остальные — нет прав
shift_list: 660
tip_report: rw-r--r--
guest_requests: 644
kitchen: rwxr-xr-x
vegetarian_menu: r--r--r--
barinov_order: 640
office: 750
vika_instruction: rw-r-----
nastya_room: rwxr-x---
nastya_diary: 640
free_tables: 700
evening_message: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `nastya_room/nastya_diary` в каталог `claude_monet/office` под именем `waitress_report`.
2. Рекурсивно скопировать каталог `claude_monet/hall/tables` в каталог `claude_monet/hall` под именем `tables_backup`.
3. В каталоге `nastya_room` создать относительную символическую ссылку `today_requests`, указывающую на файл `claude_monet/hall/guest_requests`.
4. В корне `lab0` создать символическую ссылку `hall_entry` на каталог `claude_monet/hall`.
5. Создать жёсткую ссылку `claude_monet/hall/shift_message` на файл `evening_message`.
6. Объединить содержимое файлов `claude_monet/hall/tables/table_three` и `claude_monet/hall/tables/table_seven` в новый файл `claude_monet/hall/reservation_plan`.
7. Дописать содержимое файла `claude_monet/office/vika_instruction` в конец файла `claude_monet/hall/waiters/shift_list`.
8. Переместить файл `claude_monet/hall/waiters/tip_report` в каталог `claude_monet/office` под именем `evening_tips`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке возрастания и вывести последние пять строк результата.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet` и `nastya_room`. Вывести без имён файлов строки, содержащие сочетание `настя` или `гост` в любом регистре, исключить строки с сочетанием `постоянн`, отсортировать результат по алфавиту и оставить первые шесть строк.
3. Определить, сколько файлов в исходном каталоге `claude_monet/hall/tables` и его копии `claude_monet/hall/tables_backup` содержат сочетание букв `гост` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из исходных файлов каталога `claude_monet/hall/tables` получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `столик` или `заказ` в любом регистре и отсортировать их в обратном алфавитном порядке.
5. Из файла `claude_monet/hall/reservation_plan` исключить строки с именем `Настя`, выбрать строки с сочетанием `гост` или `столик`, отсортировать их в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по имени файла в обратном алфавитном порядке.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, отсортировать их по имени ссылки и вывести последнюю строку результата.
