# Вариант 13

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--warehouse (каталог)
|  |  +--stock_list (файл)
|  |  +--rejection_log (файл)
|  +--meat_delivery (каталог)
|  |  +--senya_invoice (файл)
|  |  +--supplier_note (файл)
|  +--fish_delivery (каталог)
|  |  +--fedya_invoice (файл)
|  |  +--freshness_report (файл)
|  +--kitchen (каталог)
|  |  +--hot_station (каталог)
|  |  |  +--barinov_claim (файл)
|  |  +--cold_station (каталог)
|  |     +--fish_order (файл)
|  +--office (каталог)
|     +--vika_payment (файл)
+--delivery_call (файл)
```

Содержимое файлов:

```text
stock_list:
На складе осталось десять упаковок мяса
Свежая рыба размещена в холодильнике
Поставщик зелени ожидается вечером

rejection_log:
Поставщик забрал коробку испорченных овощей
Две упаковки мяса отправлены на возврат
Баринов потребовал заменить продукты сегодня

senya_invoice:
Говядина двадцать килограммов
Телятина десять килограммов
Поставщик мяса подтвердил вес заказа

supplier_note:
Доставка мяса задержалась на сорок минут
Сеня принял продукты на складе
Следующий заказ привезут утром

fedya_invoice:
Сибас двенадцать штук
Дорадо восемь штук
Поставщик рыбы добавил коробку льда

freshness_report:
Рыба имеет свежий запах
Температура при доставке не нарушена
Федя разрешил использовать весь заказ

barinov_claim:
Баринов недоволен опозданием машины
Шеф требует проверять каждого поставщика
Качество продуктов важнее скидки

fish_order:
Для банкета требуется свежая рыба
Федя выбрал сибаса и дорадо
Заказ нужно передать Вике

vika_payment:
Вика получила накладные от Сени и Феди
Оплата поставщикам назначена на вечер
Возврат продуктов вычитается из суммы

delivery_call:
Поставщик позвонил перед открытием ресторана
Машина с продуктами стоит у входа
Лёва должен открыть склад
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
warehouse: rwxr-x---
stock_list: 640
rejection_log: rw-r-----
meat_delivery: 750
senya_invoice: владелец — чтение и запись; группа — чтение; остальные — нет прав
supplier_note: 644
fish_delivery: rwxr-x---
fedya_invoice: 640
freshness_report: rw-r--r--
kitchen: 750
hot_station: владелец — все права; группа — чтение и исполнение; остальные — нет прав
barinov_claim: 640
cold_station: rwxr-x---
fish_order: rw-r-----
office: 750
vika_payment: 640
delivery_call: владелец — чтение и запись; группа — чтение; остальные — нет прав
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `delivery_call` в каталог `claude_monet/office` под именем `call_copy`.
2. Рекурсивно скопировать каталог `claude_monet/fish_delivery` в каталог `claude_monet/warehouse` под именем `fish_backup`.
3. В корне `lab0` создать символическую ссылку `stock_link`, указывающую на файл `claude_monet/warehouse/stock_list`.
4. В каталоге `claude_monet/kitchen` создать относительную символическую ссылку `warehouse_access`, указывающую на каталог `../warehouse`.
5. Создать жёсткую ссылку `claude_monet/meat_delivery/invoice_duplicate` на файл `claude_monet/meat_delivery/senya_invoice`.
6. Объединить содержимое файлов `claude_monet/meat_delivery/senya_invoice` и `claude_monet/fish_delivery/fedya_invoice` в новый файл `claude_monet/warehouse/all_invoices`.
7. Дописать содержимое файла `claude_monet/warehouse/rejection_log` в конец файла `claude_monet/kitchen/hot_station/barinov_claim`.
8. Переместить файл `claude_monet/kitchen/cold_station/fish_order` в каталог `claude_monet/office` под именем `urgent_fish_order`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений ввода-вывода и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, исключить имена с сочетанием `copy`, отсортировать строки по размеру файла как по числу в порядке возрастания и вывести последние пять строк.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet`. Вывести без имён файлов строки, содержащие сочетание `поставщик` или `продукт` в любом регистре, исключить строки с сочетанием `утром`, отсортировать результат по алфавиту и оставить первые шесть строк.
3. Определить, сколько файлов в исходном каталоге `claude_monet/fish_delivery` и его копии `claude_monet/warehouse/fish_backup` содержат сочетание букв `рыб` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из исходных файлов с окончанием имени `_invoice` в каталогах `meat_delivery` и `fish_delivery` получить последние две строки без служебных заголовков. Оставить строки с сочетанием `поставщик`, `килограмм` или `штук` в любом регистре и отсортировать их в обратном алфавитном порядке.
5. Из файла `claude_monet/warehouse/all_invoices` исключить строки с сочетанием `поставщик`, отсортировать оставшиеся строки в обратном алфавитном порядке, взять первые три и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по номеру inode как по числу.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, отсортировать их по имени ссылки и вывести последнюю строку результата.

## 5. Удаление файлов, ссылок и каталогов

Выполнить следующие действия при помощи команд `rm` и `rmdir`:

1. Удалить файл `claude_monet/office/call_copy`.
2. Удалить символическую ссылку `stock_link`.
3. Удалить символическую ссылку `claude_monet/kitchen/warehouse_access`.
4. Удалить жёсткую ссылку `claude_monet/meat_delivery/invoice_duplicate`.
5. Удалить файл `claude_monet/office/urgent_fish_order`.
6. Удалить ставший пустым каталог `claude_monet/kitchen/cold_station` при помощи `rmdir`.
7. Удалить файл `claude_monet/warehouse/rejection_log`.
8. Удалить каталог `claude_monet/warehouse/fish_backup` со всем его содержимым.
