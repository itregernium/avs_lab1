# Лабораторная работа №1

### Установка

Для выполнения лабораторной работы потребуется установленный Docker. Все задания необходимо выполнять в контейнере с `Debian 13`.

Загрузите образ и создайте контейнер:

```bash
docker pull debian:13-slim
docker run -d --name avs-lab -e LANG=C.UTF-8 -e LC_ALL=C.UTF-8 debian:13-slim sleep infinity
```

Подготовьте непривилегированного пользователя и установите отсутствующую в минимальном образе команду `less`:

```bash
docker exec -e DEBIAN_FRONTEND=noninteractive avs-lab bash -c "apt-get update && apt-get install -y less && useradd -m -s /bin/bash student"
```

Эти действия относятся только к подготовке окружения. Команды `apt-get` и `useradd` нельзя использовать при выполнении лабораторной работы.

Откройте терминал внутри контейнера от имени созданного пользователя:

```bash
docker exec -it -u student -w /home/student avs-lab bash
```

Если контейнер был остановлен, сначала запустите его командой `docker start avs-lab`, а затем снова выполните `docker exec`. Все файлы лабораторной работы создавайте внутри контейнера в домашнем каталоге пользователя `student`.
