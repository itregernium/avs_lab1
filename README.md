# Лабораторная работа №1. Поднятие рабочего пространства. Bash команды.

# Учебные цели и задачи.

Цель данной ЛР - формирование у студентов практических навыков развёртывания изолированного рабочего пространства разработчика средствами контейнеризации (Docker, VS Code) и системы контроля версий Git, а также освоение базовых возможностей командной оболочки Bash ОС Linux (Debian) для работы с файлами и каталогами, управления правами доступа, поиска и фильтрации данных.

По методическим рекомендациям цель дополняется планируемыми результатами обучения:

- **Знать:** назначение и принципы работы Docker и Dev-контейнеров, Git/GitHub, структуру базовых команд Bash и их параметров.

- **Уметь:** поднимать и настраивать Dev-контейнер в VS Code; выполнять в терминале команды создания и редактирования файлов и каталогов, управления правами доступа, поиска и фильтрации данных; инициализировать репозиторий и публиковать изменения в удалённый репозиторий GitHub.

- **Владеть:** навыками написания исполняемых shell-скриптов, последовательно выполняющих задания варианта, и оформления отчёта по результатам работы.

# Описание лабораторной работы.

## 1. Подготовительная часть. Скачивание программ.

Для выполнения лабораторной работы потребуется установленный Docker. Скачайте его с сайта [docker.com](https://www.docker.com/), зарегистрируйтесь.

Для выполнения работы также потребуется установленный Git и Github аккаунт. Перейдите на сайт [github.com](https://github.com/), зарегиструйтесь, настройте себе профиль. Можете скачать приложение с интерфейсом, например - Github Desktop.

Напоследок, для выполнения работы потребуется Visual Studio Code. Зайдите на сайт [code.visualstudio.com](https://code.visualstudio.com/), выполните инструкцию по установке. Внутри интерфейса, слева снизу авторизуйтесь на через аккаунт Github.

## 2. Настройка VSCode и контейнера.

С этой точки, все задания необходимо выполнять внутри программы Visual Studio Code.

Внутри интерфейса Visual Studio Code, в самом нижнем левом углу нажмите ">< Open a Remote Window" → "New Dev Container". В поиске наберите "debian" и выберите опцию "Debian (от devcontainers): Simple Debian container with Git Installed". Загрузите образ и запустите контейнер (загрузка и сборка займет некоторое время).

Откройте терминал запущенного контейнера и убедитесь, что всё работает, введя команду:

```Shell
apt-get update && apt-get install -y less
```


Эта команда установит отсутствующую в минимальной сборке команду `less`. Таким образом, можно установить любую недостающую команду.

## 3. Работа в терминале VSCode.

На этом этапе предлагается на практике познакомиться с некоторыми возможностями терминала: создавать файлы и каталоги, редактировать их содержимое, устанавливать права доступа и выполнять поиск и фильтрацию данных.

**Все файлы лабораторной работы создавайте внутри контейнера разработки.** Задания варианта необходимо выполнять последовательно.

Разрешено использовать только ограниченный пул команд.

  Команды linux: `mkdir`, `echo`, `cat`, `touch`, `chmod`, `ls`, `pwd`, `cd`, `less`, `head`, `tail`, `cp`, `ln`, `rm`, `rmdir`, `mv`, `wc`, `sort`, `grep`. По каждой команде можно получить справку в терминале: `man [КОМАНДА]`.

  Команды git: `git init`, `git status`, `git add`, `git commit`, `git log`, `git push`. По каждой команде можно получить справку: `git help`.

Варианты доступны по ссылке: [https://github.com/itregernium/avs_lab1](https://github.com/itregernium/avs_lab1)

*В соответствии с вашим табельным номером ИСУ выберите свой вариант: вариант = ИСУ mod 15 + 1. Пример: 408366 % 15 + 1 = 7.*

Через окно терминала, внутри запущенного контейнера разработки в Visual Studio Code, выполните следующие действия:

### Часть 1.

  1. Инициализировать репозиторий с помощью команды `git init`.

  2. Создать приведённое в варианте дерево каталогов и файлов с содержимым. В качестве корня дерева использовать каталог `lab0` своего домашнего каталога.

  3. Установить права на файлы и каталоги, используя числовой и символьный способы указания прав.

  4. Используя команды `git status`, `git add` и `git commit`, проверить статус репозитория, закинуть все измененные файлы в индекс и сделать первый коммит. Дайте ему осмысленное сообщение.

  5. Опубликовать репозиторий с помощью команды `git push`.

### Часть 2.

  1. Скопировать часть дерева и создать ссылки внутри дерева при помощи команд `cp` и `ln`, а также комманды `cat` и перенаправления ввода-вывода.

  2. Проверить статус репозитория, закинуть все измененные файлы в индекс. Сделать коммит и опубликовать.

### Часть 3.

  1. Используя команды `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep` выполнить поиск и фильтрацию файлов, каталогов и содержащихся в них данных.

  2. Выполнить удаление файлов и каталогов при помощи команд `rm` и `rmdir`.

  3. Проверить статус репозитория, закинуть все измененные файлы в индекс. Сделать коммит и опубликовать.

Откройте и посмотрите страницу своего удалённого репозитория на Github. Изучите историю коммитов, сообщения коммитов, авторство. Посмотрите, как выглядят изменённые файлы.

# Формат сдачи.

Студент обязан предоставить:

- Один или несколько исполняемых shell-скриптов, которые последовательно выполняют все пункты варианта.

- Отчёт в формате Word или PDF, соответствующий следующим критериям:

  1. Официальный титульный лист, предоставленный преподавателем

  2. Содержание отчёта

  3. Основная часть, состоящая из последовательных шагов, описывающих выполнение всех пунктов варианта, вместе со скриншотами выполненных команд. Обязательно указать вариант автора отчёта.

  4. Вывод, описывающий знания, умения и навыки, которые были получены студентом в рамках выполненной лабораторной работы. 

  6. Использование GAI, с обязательным указанием конкретной модели, цели использования, промптов и результатов работы модели и **ссылкой на диалог**.

  7. Список источников/литературы.
