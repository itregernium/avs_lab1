# Вариант 12

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--kitchen (каталог)
|  |  +--hot_station (каталог)
|  |  |  +--hot_report (файл)
|  |  |  +--senya_check (файл)
|  |  +--cold_room (каталог)
|  |     +--fridge_temperature (файл)
|  |     +--fish_check (файл)
|  +--sanitation (каталог)
|  |  +--inspection_act (файл)
|  |  +--violations (файл)
|  +--cleaning (каталог)
|  |  +--cleaning_schedule (файл)
|  +--hall (каталог)
|  |  +--waiter_note (файл)
|  +--office (каталог)
|     +--vika_response (файл)
+--inspector_arrival (файл)
```

Содержимое файлов:

```text
hot_report:
Горячий цех подготовлен к проверке
Рабочие поверхности очищены
Баринов проверил порядок лично

senya_check:
Сеня убрал лишние продукты
Ножи лежат на своих местах
Срок хранения мяса не нарушен

fridge_temperature:
Утром температура четыре градуса
Днём температура пять градусов
Вечером температура четыре градуса

fish_check:
Федя проверил сибаса и дорадо
Свежая рыба перенесена в холодильник
Нарушений хранения рыбы нет

inspection_act:
Проверка началась до открытия ресторана
Инспектор осмотрел кухню и зал
Повторная проверка назначена на пятницу

violations:
Нарушен порядок хранения одной коробки
Нарушена маркировка контейнера с соусом
График уборки висит не на своём месте

cleaning_schedule:
Уборка кухни проводится утром
Уборка зала проводится перед открытием
Вечером Лёва проверяет результат уборки

waiter_note:
Официанты убрали столы перед проверкой
Настя проверила гостевую зону
Запасные скатерти сложены в шкаф

vika_response:
Вика получила акт инспектора
Замечания будут исправлены до вечера
Ответственным назначен Лёва

inspector_arrival:
Инспектор приехал раньше назначенного времени
Баринов встретил проверку на кухне
Нагиев потребовал избежать штрафа
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
kitchen: rwxr-x---
hot_station: 750
hot_report: rw-r-----
senya_check: 640
cold_room: владелец — все права; группа — чтение и исполнение; остальные — нет прав
fridge_temperature: 644
fish_check: rw-r-----
sanitation: 750
inspection_act: владелец — чтение и запись; группа — чтение; остальные — нет прав
violations: 640
cleaning: rwxr-x---
cleaning_schedule: 644
hall: 755
waiter_note: rw-r--r--
office: владелец — все права; группа — чтение и исполнение; остальные — нет прав
vika_response: 640
inspector_arrival: rw-r-----
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `inspector_arrival` в каталог `claude_monet/office` под именем `arrival_copy`.
2. Рекурсивно скопировать каталог `claude_monet/cleaning` в каталог `claude_monet/sanitation` под именем `cleaning_backup`.
3. В корне `lab0` создать символическую ссылку `inspection_link`, указывающую на файл `claude_monet/sanitation/inspection_act`.
4. В каталоге `claude_monet/kitchen` создать относительную символическую ссылку `sanitation_access`, указывающую на каталог `../sanitation`.
5. Создать жёсткую ссылку `claude_monet/sanitation/act_duplicate` на файл `claude_monet/sanitation/inspection_act`.
6. Объединить содержимое файлов `claude_monet/kitchen/hot_station/hot_report` и `claude_monet/kitchen/cold_room/fish_check` в новый файл `claude_monet/kitchen/stations_report`.
7. Дописать содержимое файла `claude_monet/sanitation/violations` в конец файла `claude_monet/office/vika_response`.
8. Переместить файл `claude_monet/hall/waiter_note` в каталог `claude_monet/office` под именем `guest_zone_note`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений ввода-вывода и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке убывания и вывести первые пять строк результата.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet`. Вывести без имён файлов строки, содержащие сочетание `наруш` или `проверк` в любом регистре, исключить строки с сочетанием `повторн`, отсортировать результат в обратном алфавитном порядке и оставить первые шесть строк.
3. Определить, сколько файлов в каталогах `claude_monet/cleaning` и `claude_monet/sanitation/cleaning_backup` содержат сочетание букв `уборк` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из файлов с окончаниями имени `_report` и `_check` в каталогах `hot_station` и `cold_room` получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `провер` или `наруш` в любом регистре и отсортировать их по алфавиту.
5. Из файла `claude_monet/kitchen/stations_report` исключить строки с именем `Баринов`, выбрать строки с сочетанием `провер` или `рыб`, отсортировать их в обратном алфавитном порядке и подсчитать общее количество слов.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Отсортировать полученные строки по имени файла.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, отсортировать их по имени ссылки в обратном алфавитном порядке и вывести первую строку результата.

## 5. Удаление файлов, ссылок и каталогов

Выполнить следующие действия при помощи команд `rm` и `rmdir`:

1. Удалить файл `claude_monet/office/arrival_copy`.
2. Удалить символическую ссылку `inspection_link`.
3. Удалить символическую ссылку `claude_monet/kitchen/sanitation_access`.
4. Удалить жёсткую ссылку `claude_monet/sanitation/act_duplicate`.
5. Удалить файл `claude_monet/office/guest_zone_note`.
6. Удалить ставший пустым каталог `claude_monet/hall` при помощи `rmdir`.
7. Удалить файл `claude_monet/sanitation/violations`.
8. Удалить каталог `claude_monet/sanitation/cleaning_backup` со всем его содержимым.
