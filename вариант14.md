# Вариант 14

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--victor (каталог)
|  +--kitchen (каталог)
|  |  +--barinov_plan (файл)
|  |  +--max_dish (файл)
|  +--pastry (каталог)
|  |  +--katya_dessert (файл)
|  +--hall (каталог)
|  |  +--opening_tables (файл)
|  |  +--guest_list (файл)
|  +--reception (каталог)
|  |  +--reservations (файл)
|  +--management (каталог)
|     +--eleonora_order (файл)
|     +--vika_schedule (файл)
+--archive (каталог)
|  +--old_menu (файл)
+--claude_monet (каталог)
|  +--farewell_note (файл)
+--opening_day (файл)
```

Содержимое файлов:

```text
barinov_plan:

Лёва распределяет поваров по рабочим местам
Новое меню готовят к вечернему открытию

Макс предлагает утку с новым соусом
Баринов разрешает приготовить пробную порцию
Блюдо подадут первым гостям ресторана Victor

katya_dessert:
Катя готовит шоколадный десерт
Украшение собирают перед самой подачей
Элеонора ждёт результат дегустации

opening_tables:
Первый стол оставлен для Элеоноры
Второй стол подготовлен для Нагиева
Большой стол займёт команда ресторана

guest_list:
Элеонора Андреевна прибывает к открытию
Дмитрий Нагиев приглашён на ужин
Денис выступает для гостей вечером

reservations:
Столик четыре забронирован на семь часов

eleonora_order:
Элеонора требует закончить подготовку вовремя

Утром проверить работу кухни

Луковый суп из Claude Monet

Фирменное мясо от Баринова

farewell_note:
Команда прощается с рестораном Claude Monet
Старые рецепты сохраняются в архиве
Макс обещает не забывать первую кухню

Ресторан Victor открывается вечером
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
victor: 755
kitchen: rwxr-x---
barinov_plan: 640
max_dish: rw-r-----
pastry: 750
katya_dessert: владелец — чтение и запись; группа — чтение; остальные — нет прав
hall: rwxr-x---
opening_tables: 644
guest_list: rw-r--r--
reception: 750
reservations: 640
management: владелец — все права; группа — чтение и исполнение; остальные — нет прав
eleonora_order: rw-r-----
vika_schedule: 640
archive: rwxr-x---
old_menu: 644
claude_monet: 755
farewell_note: владелец — чтение и запись; группа — чтение; остальные — нет прав
opening_day: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `opening_day` в каталог `victor/management` под именем `opening_copy`.
2. Рекурсивно скопировать каталог `claude_monet` в каталог `archive` под именем `claude_backup`.
3. В корне `lab0` создать символическую ссылку `victor_menu`, указывающую на файл `victor/kitchen/barinov_plan`.
4. В каталоге `victor/reception` создать относительную символическую ссылку `hall_access`, указывающую на каталог `../hall`.
5. Создать жёсткую ссылку `victor/hall/guest_list_copy` на файл `victor/hall/guest_list`.
6. Объединить содержимое файлов `victor/kitchen/max_dish` и `victor/pastry/katya_dessert` в новый файл `victor/kitchen/tasting_menu`.
7. Дописать содержимое файла `victor/reception/reservations` в конец файла `victor/management/vika_schedule`.
8. Переместить файл `claude_monet/farewell_note` в каталог `victor/management` под именем `farewell_note`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений ввода-вывода и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, исключить имена с сочетанием `copy`, отсортировать строки по размеру файла как по числу в порядке убывания и вывести первые пять строк.
2. Рекурсивно просмотреть содержимое файлов в `victor` и `archive`. Вывести без имён файлов строки, содержащие сочетание `victor` или `баринов` в любом регистре, исключить строки с сочетанием `стар`, отсортировать результат в обратном алфавитном порядке и оставить первые шесть строк.
3. Определить, сколько файлов в каталогах `victor/kitchen` и `archive/claude_backup` содержат сочетание `макс` или `кухн` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из исходных файлов каталога `victor/hall`, имена которых начинаются на `guest_` или `opening_`, получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `гост` или `стол` в любом регистре и отсортировать их по алфавиту.
5. Из файла `victor/kitchen/tasting_menu` исключить строки с сочетанием `десерт`, выбрать строки с сочетанием `макс` или `блюд`, отсортировать их в обратном алфавитном порядке и подсчитать общее количество слов.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по имени файла в обратном алфавитном порядке.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, отсортировать их по имени ссылки и вывести первую строку результата.

## 5. Удаление файлов, ссылок и каталогов

Выполнить следующие действия при помощи команд `rm` и `rmdir`:

1. Удалить файл `victor/management/opening_copy`.
2. Удалить символическую ссылку `victor_menu`.
3. Удалить символическую ссылку `victor/reception/hall_access`.
4. Удалить жёсткую ссылку `victor/hall/guest_list_copy`.
5. Удалить файл `victor/management/farewell_note`.
6. Удалить ставший пустым каталог `claude_monet` при помощи `rmdir`.
7. Удалить файл `archive/old_menu`.
8. Удалить каталог `archive/claude_backup` со всем его содержимым.
