# Вариант 11

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--owner_office (каталог)
|  |  +--owner_order (файл)
|  |  +--expense_plan (файл)
|  +--contracts (каталог)
|  |  +--supplier_contract (файл)
|  |  +--concert_contract (файл)
|  +--advertising (каталог)
|  |  +--promo_plan (файл)
|  +--kitchen (каталог)
|  |  +--chef_order (файл)
|  |  +--menu_prices (файл)
|  +--chef_office (каталог)
|  |  +--barinov_reply (файл)
|  +--hall (каталог)
|     +--vip_guests (файл)
+--archive (каталог)
+--nagiev_call (файл)
```

Содержимое файлов:

```text
owner_order:
Дмитрий Нагиев требует подготовить ресторан к съёмке
Виктор Петрович должен представить новое меню
Вика отвечает за порядок в зале

expense_plan:
Новая вывеска требует согласования
Реклама ресторана оплачивается владельцем
Расходы на банкет проверить отдельно

supplier_contract:
Поставщик привозит продукты утром
Шеф лично проверяет качество мяса
Оплата производится после приёмки

concert_contract:
Музыканты выступают в пятницу вечером
Костя готовит напитки для артистов
Вика согласует время начала программы

promo_plan:
Реклама показывает кухню и главный зал
Нагиев появляется в финале рекламного ролика
Баринов отказывается повторять текст дважды

chef_order:
Приготовить фирменное блюдо к восьми часам
Сеня и Федя отвечают за горячий цех
Лёва проверяет выдачу каждого блюда

menu_prices:
Утиная ножка 850
Луковый суп 430
Мильфей 520
Стейк от шефа 1100

barinov_reply:
Баринов согласен обновить меню
Баринов не согласен сниматься в рекламе
Все решения по кухне принимает шеф

vip_guests:
За первым столом сидят актёры
Для Нагиева оставить место у сцены
Постоянным гостям подать десерт от Луи

nagiev_call:
Нагиев позвонил Вике утром
Владелец приедет после открытия
Отчёт о расходах должен быть готов
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
owner_office: rwxr-x---
owner_order: 640
expense_plan: владелец — чтение и запись; группа — чтение; остальные — нет прав
contracts: 750
supplier_contract: rw-r-----
concert_contract: 640
advertising: владелец — все права; группа — чтение и исполнение; остальные — нет прав
promo_plan: 644
kitchen: rwxr-x---
chef_order: 640
menu_prices: rw-r--r--
chef_office: 750
barinov_reply: владелец — чтение и запись; группа — чтение; остальные — нет прав
hall: 755
vip_guests: rw-r--r--
archive: rwxr-x---
nagiev_call: 640
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `nagiev_call` в каталог `claude_monet/owner_office` под именем `nagiev_call_copy`.
2. Рекурсивно скопировать каталог `claude_monet/advertising` в каталог `claude_monet/owner_office` под именем `advertising_backup`.
3. В корне `lab0` создать символическую ссылку `owner_contract`, указывающую на файл `claude_monet/contracts/supplier_contract`.
4. В каталоге `claude_monet/owner_office` создать относительную символическую ссылку `hall_access`, указывающую на каталог `../hall`.
5. Создать жёсткую ссылку `claude_monet/contracts/supplier_duplicate` на файл `claude_monet/contracts/supplier_contract`.
6. Объединить содержимое файлов `claude_monet/owner_office/owner_order` и `claude_monet/chef_office/barinov_reply` в новый файл `claude_monet/owner_office/meeting_notes`.
7. Дописать содержимое файла `claude_monet/kitchen/chef_order` в конец файла `nagiev_call`.
8. Переместить файл `claude_monet/advertising/promo_plan` в каталог `archive` под именем `promo_final`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений ввода-вывода и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, исключить имена с сочетанием `copy`, отсортировать строки по размеру файла как по числу в порядке убывания и вывести первые пять строк.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet` и `archive`. Вывести без имён файлов строки, содержащие сочетание `нагиев` или `баринов` в любом регистре, исключить строки с сочетанием `реклам`, отсортировать результат в обратном алфавитном порядке и оставить первые пять строк.
3. Определить, сколько файлов в каталогах `claude_monet/contracts` и `claude_monet/owner_office` содержат сочетание букв `поставщик` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из исходных файлов каталога `claude_monet/contracts` получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `поставщик`, `музыкант` или `оплат` в любом регистре и отсортировать их по алфавиту.
5. Из файла `claude_monet/owner_office/meeting_notes` исключить строки с сочетанием `согласен`, выбрать строки с сочетанием `меню` или `кухн`, отсортировать их в обратном алфавитном порядке и подсчитать общее количество слов.
6. Из подробного рекурсивного списка `lab0` вывести только символические ссылки и отсортировать полученные строки по имени ссылки в обратном алфавитном порядке.
7. В файлах каталога `claude_monet/owner_office/advertising_backup` выбрать без вывода имён файлов строки с сочетанием `реклам`, исключить строки с именем `Нагиев`, отсортировать результат по алфавиту и подсчитать количество оставшихся слов.

## 5. Удаление файлов, ссылок и каталогов

Выполнить следующие действия при помощи команд `rm` и `rmdir`:

1. Удалить файл `claude_monet/owner_office/nagiev_call_copy`.
2. Удалить символическую ссылку `owner_contract`.
3. Удалить символическую ссылку `claude_monet/owner_office/hall_access`.
4. Удалить жёсткую ссылку `claude_monet/contracts/supplier_duplicate`.
5. Удалить файл `claude_monet/hall/vip_guests`.
6. Удалить ставший пустым каталог `claude_monet/hall` при помощи `rmdir`.
7. Удалить ставший пустым каталог `claude_monet/advertising` при помощи `rmdir`.
8. Удалить каталог `claude_monet/owner_office/advertising_backup` со всем его содержимым.
