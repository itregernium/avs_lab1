# Вариант 6

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--victor (каталог)
|  +--kitchen (каталог)
|  |  +--molecular_station (каталог)
|  |  |  +--foam_recipe (файл)
|  |  |  +--nitrogen_notes (файл)
|  |  +--hot_station (каталог)
|  |  |  +--senya_report (файл)
|  |  |  +--fedya_report (файл)
|  |  +--chef_order (файл)
|  +--hall (каталог)
|  |  +--reservations (файл)
|  |  +--guest_reviews (файл)
|  +--office (каталог)
|     +--katya_schedule (файл)
+--experiments (каталог)
|  +--tasting_results (файл)
+--archive_empty (каталог)
+--opening_message (файл)
```

Содержимое файлов:

```text

Катя готовит свекольную пену для нового блюда
Лёва проверяет температуру перед подачей
Баринов требует сохранить вкус продуктов
Рецепт отправят на вечернюю дегустацию

Баллон с азотом доставлен утром

Сеня держится подальше от оборудования
После опыта рабочее место нужно убрать

senya_report:
Сеня подготовил мясо для горячего блюда
Первая партия отправлена в зал
Шеф потребовал переделать соус
К вечеру заказ был выполнен

fedya_report:
Федя получил свежую рыбу
Дорадо подготовлена для постоянных гостей
Катя предложила необычную подачу блюда
Баринов одобрил только второй вариант

chef_order:
Баринов проводит дегустацию после обеда
Каждый повар представляет одно новое блюдо
Катя отвечает за молекулярную часть меню
Результаты передать Лёве до вечерней смены

reservations:
Столик два забронирован для критика
Столик пять подготовить к семнадцати часам
Большой стол оставить для команды ресторана

guest_reviews:

katya_schedule:
Катя приходит на кухню к десяти часам
До обеда проводится первый опыт
После дегустации нужно встретиться с Бариновым
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
victor: 755
kitchen: rwxr-x---
molecular_station: 750
foam_recipe: rw-r-----
nitrogen_notes: 640
hot_station: владелец — все права; группа — чтение и исполнение; остальные — нет прав
senya_report: 644
fedya_report: rw-r--r--
chef_order: 640
hall: rwxr-xr-x
reservations: 664
guest_reviews: r--r--r--
office: 750
katya_schedule: rw-r-----
experiments: rwxr-x---
tasting_results: 660
archive_empty: 700
opening_message: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `experiments/tasting_results` в каталог `victor/office` под именем `successful_experiment`.
2. Рекурсивно скопировать каталог `victor/kitchen/molecular_station` в каталог `experiments` под именем `molecular_backup`.
3. В каталоге `experiments` создать относительную символическую ссылку `current_recipe`, указывающую на файл `victor/kitchen/molecular_station/foam_recipe`.
4. В корне `lab0` создать символическую ссылку `kitchen_entry` на каталог `victor/kitchen`.
5. Создать жёсткую ссылку `victor/kitchen/shift_order` на файл `opening_message`.
6. Объединить содержимое файлов `victor/kitchen/hot_station/senya_report` и `victor/kitchen/hot_station/fedya_report` в новый файл `victor/kitchen/team_report`.
7. Дописать содержимое файла `victor/kitchen/chef_order` в конец файла `experiments/tasting_results`.
8. Переместить файл `victor/hall/reservations` в каталог `victor/office` под именем `evening_reservations`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, отсортировать их по размеру файла как по числу в порядке возрастания и вывести последние пять строк результата.
2. Рекурсивно просмотреть содержимое файлов в `victor` и `experiments`. Вывести без имён файлов строки, содержащие сочетание `катя` или `баринов` в любом регистре, исключить строки с сочетанием `гост`, отсортировать результат в обратном алфавитном порядке и оставить первые шесть строк.
3. Определить, сколько файлов в исходном каталоге `victor/kitchen/molecular_station` и его копии `experiments/molecular_backup` содержат сочетание букв `катя` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из исходных файлов с окончанием имени `_report` в каталоге `victor/kitchen/hot_station` получить первую и последнюю строку без служебных заголовков. Оставить строки с сочетанием `блюд` или `баринов` в любом регистре и отсортировать их по алфавиту.
5. Из файла `victor/kitchen/team_report` исключить строки с именами `Сеня` и `Федя`, выбрать строки с сочетанием `блюд`, отсортировать их в обратном алфавитном порядке и подсчитать общее количество слов.
6. Из подробного рекурсивного списка `lab0` вывести только символические ссылки и отсортировать полученные строки по имени ссылки в обратном алфавитном порядке.
7. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Отсортировать полученные строки по номеру inode как по числу.

## 5. Удаление файлов, ссылок и каталогов

Выполнить действия при помощи команд `rm` и `rmdir`:

1. Удалить исходный файл `experiments/tasting_results`.
2. Удалить символическую ссылку `experiments/current_recipe`.
3. Удалить символическую ссылку `kitchen_entry`.
4. Удалить исходный файл `opening_message`, не удаляя созданную для него жёсткую ссылку.
5. Удалить жёсткую ссылку `victor/kitchen/shift_order`.
6. Удалить файл `victor/kitchen/molecular_station/nitrogen_notes`.
7. Удалить пустой каталог `archive_empty` при помощи `rmdir`.
8. Удалить каталог `experiments/molecular_backup` со всем его содержимым.
