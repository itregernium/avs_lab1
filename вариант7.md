# Вариант 7

## 1. Создание дерева каталогов и файлов

Создать приведённое ниже дерево каталогов и файлов. В качестве корня дерева использовать каталог `lab0` в своём домашнем каталоге.

```text
~/lab0 (каталог)
+--claude_monet (каталог)
|  +--pastry_station (каталог)
|  |  +--oven (каталог)
|  |  |  +--croissant_plan (файл)
|  |  |  +--millefeuille_plan (файл)
|  |  +--cold_room (каталог)
|  |  |  +--cream_note (файл)
|  |  +--dessert_menu (файл)
|  +--hall (каталог)
|  |  +--banquet_orders (файл)
|  |  +--guest_wishes (файл)
|  +--office (каталог)
|     +--barinov_comment (файл)
+--louis_room (каталог)
|  +--louis_diary (файл)
|  +--work_schedule (файл)
+--empty_boxes (каталог)
+--morning_order (файл)
```

Содержимое файлов:

```text

Баринов проверит выпечку лично

dessert_menu:

Мильфей с ванильным кремом

guest_wishes:
Постоянный гость просит десерт без орехов
```

## 2. Установка прав доступа

Установить указанные права на файлы и каталоги. Права, записанные числом, установить числовым способом; права, записанные буквами или словами, — символьным способом.

```text
claude_monet: 755
pastry_station: rwxr-x---
oven: 750
croissant_plan: rw-r-----
millefeuille_plan: 640
cold_room: владелец — все права; группа — чтение и исполнение; остальные — нет прав
cream_note: 600
dessert_menu: rw-r--r--
hall: 755
banquet_orders: rw-rw-r--
guest_wishes: 644
office: rwxr-x---
barinov_comment: 640
louis_room: 750
louis_diary: r--r-----
work_schedule: 644
empty_boxes: rwx------
morning_order: rw-r--r--
```

## 3. Копирование, перемещение и создание ссылок

Выполнить следующие действия при помощи команд `cp`, `ln`, `mv`, `cat` и перенаправлений ввода-вывода:

1. Скопировать файл `louis_room/louis_diary` в каталог `claude_monet/office` под именем `confectioner_report`.
2. Рекурсивно скопировать каталог `claude_monet/hall` в каталог `claude_monet/pastry_station` под именем `hall_backup`.
3. В каталоге `louis_room` создать относительную символическую ссылку `today_menu`, указывающую на файл `claude_monet/pastry_station/dessert_menu`.
4. В корне `lab0` создать символическую ссылку `dessert_counter` на каталог `claude_monet/pastry_station`.
5. Создать жёсткую ссылку `claude_monet/pastry_station/urgent_order` на файл `morning_order`.
6. Объединить содержимое файлов `claude_monet/pastry_station/oven/croissant_plan` и `claude_monet/pastry_station/oven/millefeuille_plan` в новый файл `claude_monet/pastry_station/baking_plan`.
7. Дописать содержимое файла `claude_monet/office/barinov_comment` в конец файла `claude_monet/pastry_station/dessert_menu`.
8. Переместить файл `claude_monet/hall/guest_wishes` в каталог `claude_monet/office` под именем `special_wishes`.

## 4. Поиск, фильтрация и обработка данных

Выполнить задания при помощи команд `cat`, `wc`, `ls`, `head`, `tail`, `echo`, `sort`, `grep`, конвейеров, перенаправлений и масок:

1. Получить подробный рекурсивный список содержимого `lab0`. Оставить только строки, описывающие обычные файлы, исключить имена с сочетанием `report`, отсортировать строки по размеру файла как по числу в порядке возрастания и вывести последние пять строк.
2. Рекурсивно просмотреть содержимое файлов в `claude_monet` и `louis_room`. Вывести без имён файлов строки, содержащие сочетание `луи` или `десерт` в любом регистре, исключить строки с сочетанием `гост`, отсортировать результат в обратном алфавитном порядке и оставить первые пять строк.
3. Определить, сколько файлов в каталогах `claude_monet/hall` и `claude_monet/pastry_station/hall_backup` содержат сочетание букв `десерт` хотя бы один раз. Подсчитать количество файлов, а не количество совпавших строк.
4. Из файлов с окончанием имени `_plan` в каталоге `claude_monet/pastry_station/oven` получить последние две строки без служебных заголовков. Оставить строки с сочетанием `десерт` или `порц` в любом регистре и отсортировать их по алфавиту.
5. Из файла `claude_monet/pastry_station/baking_plan` исключить строки с именем `Луи`, отсортировать оставшиеся строки в обратном алфавитном порядке, взять первые четыре и подсчитать общее количество слов в них.
6. Из подробного рекурсивного списка `lab0` вывести только обычные файлы, для которых количество жёстких ссылок равно двум. Полученные строки отсортировать по имени файла в обратном алфавитном порядке.
7. Из подробного рекурсивного списка `lab0` вывести только символические ссылки, отсортировать их по имени ссылки и вывести последнюю строку результата.
